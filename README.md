
# 🎓 FuturePath - Career Guidance Chat App for Sri Lankan Students 🇱🇰  

**FuturePath** is a real-time, end-to-end encrypted chat application designed to help Sri Lankan school students discover their future career paths.  

## ✨ Features  

✅ **MCQ-Based Career Assessment** – Students take multiple-choice exams to evaluate their skills and interests.  
✅ **Automated Career Path Selection** – The system suggests suitable career paths based on exam results.  
✅ **Instructor Guidance** – Assigned instructors provide career counseling and mentorship.  
✅ **Real-Time Chat** – Secure, instant messaging between students and instructors.  
✅ **End-to-End Encryption** – Ensures privacy and security in communication.  

## 🚀 Technologies Used  

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Real-Time Communication:** AJAX, WebSockets  
- **Security:** AES Encryption  

## 📌 How It Works  

1. **Student Registration** – Users sign up and create a profile.  
2. **Take the MCQ Exam** – The system evaluates responses and assigns a career path.  
3. **Instructor Assignment** – A mentor is assigned based on the selected career.  
4. **Secure Chat** – Students and instructors communicate through encrypted real-time chat.
